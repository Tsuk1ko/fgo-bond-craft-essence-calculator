# 自动配队页面实施计划

按 `docs/自动配队界面设计.md` 与 `docs/mockups/auto-team.html` 实施。使用 writing-plans 梳理步骤，在当前工作区直接执行；不创建工作树或提交。按用户后续要求增加 Comlink 封装 Worker 调用。

## 目标与接口

- `App.vue` 提供 `#viewer` / `#team`；提取 `ViewerPage.vue`，保留查看器行为与状态。
- `AutoTeamPage.vue` 管理 `PlannerInput`，共用隐藏名单，独立保存页面筛选；Dialog 筛选关闭即丢弃。
- 格位、礼装浮层、从者 Dialog、配额表按责任拆分，复用现有筛选和图像组件。
- Web Worker 初始化原始图鉴与完整礼装目录，运行 `solve(input)`，返回结果或中文错误；计算中不阻塞页面。
- `lockedCes` 增加 `'empty'` 表示锁定空置；`null` 仍为自动，输出空置仍为 `null`。空置本身不强制上场，格位分配优先保留更多可用礼装位。

## 重点验证

1. `null` 自动与 `'empty'` 空置不会互相混淆，锁定空置不消耗礼装库存。
2. 本队有限库存不可重复；助战使用独立完整库存，改回本队时移除不合法锁定并提示。
3. 关闭冠位仅丢弃第二礼装；取消锁定或转助战清理羁绊15与开放16。
4. 修改或计算中修改输入后，旧结果必须标记过期，不能冒充新结果。
5. 窄屏只由主列滚动，配额表局部横滚；Dialog/Popover 可键盘操作并恢复焦点。

## 验证结果

- 201 项 Bun 测试通过，含两种配队模式下空置约束的独立穷举对照。
- 类型检查、生产构建、Prettier 检查、diff 空白检查通过。ESLint 无错误；保留既有 `yield.ts` 导入排序警告。
- 浏览器验证：桌面与 375px、刷新深链、入口切换保留状态、Dialog 私有筛选重置与真从者列表、重复锁定提示、助战/冠位、礼装空置、超预算错误恢复、输入变化后结果过期。
- 独立审查发现操作条可能被展开的设置推到屏幕外，已加视口底部约束并通过浏览器验证；同时修正窄屏 Dialog 默认下边距造成的额外滚动。
